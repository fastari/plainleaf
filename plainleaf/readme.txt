A calm, text-first block theme for blogs and newsletters, built to be rebranded and run with AI.

== Description ==

Plainleaf is a full site editing block theme for writers. Your colors, fonts, logo and
every sentence visitors read live in WordPress settings, not in the theme files, so
updates never overwrite your branding.

* Five color palettes and five font pairings (Appearance > Editor > Styles), plus a
  neutral default and a dark palette. Every palette passes WCAG AA contrast.
* Logo, author photo, newsletter connection, social links and the footer credit:
  Appearance > Theme settings.
* All visible text: Appearance > Site text.
* Newsletter signup that works with any tool (plugin shortcode or form action URL).
* Listen and share buttons on posts, /llms.txt for AI tools, related posts, topic pages.
* Fonts are bundled; the theme makes no requests to third-party servers and adds no tracking.
* Updates itself from public GitHub releases (no account or token).

I maintain this for my own sites and don't take outside pull requests or issues.
Fork it on GitHub if you want changes: https://github.com/fastari/plainleaf
